# Benchmark Overview

BloodCellBank-Atlas provides a unified benchmark for Personalized Federated Learning under Extreme Class-Disjoint Label Skew (EC-DLS).

Supported datasets

- BLC28

- Matek-19

- Multi-focus WBC

Supported protocols

- EC-DLS

- Dirichlet non-IID

Evaluation metrics

- Local Personalization

- Global Generalization
