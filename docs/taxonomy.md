# Unified Taxonomy

The benchmark harmonizes multiple datasets into a unified blood-cell taxonomy.

Example

| Dataset | Original Label | Unified Taxonomy |
|----------|----------------|------------------|
| Matek-19 | Band neutrophil | Neutrophil (Band) |
| BLC28 | Band cell | Neutrophil (Band) |
| Multi-focus WBC | band_neutrophil | Neutrophil (Band) |

The complete mapping is provided in `metadata/taxonomy.csv`.
