# Metadata

This directory contains benchmark metadata shared with the anonymous review repository.

Contents include

- unified taxonomy

- semantic descriptions

- benchmark metadata

The complete benchmark metadata will be publicly released upon paper acceptance.

Direct           : Original label retained.
Renamed          : Equivalent class with standardized nomenclature.
Merged           : Multiple dataset-specific labels mapped to a common benchmark class.
Dataset-specific : Unique class retained in the unified taxonomy.
